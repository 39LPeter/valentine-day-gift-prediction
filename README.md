# Valentine Day Gift Prediction

A machine learning project that predicts likely gift categories for Valentine’s Day based on demographic and spending data (age, gender, historical spending).

---

## 📊 Project Overview

This project builds a predictive model to suggest optimal gift categories (or types) for Valentine’s Day, using features like age, gender, and spending history. It demonstrates data preprocessing, feature engineering, model training, and evaluation.

---

## 🛠️ Key Features

- Exploratory Data Analysis (EDA) — visualizing trends, correlations  
- Feature engineering — deriving input features from raw data  
- Model training & evaluation — comparison of algorithms (e.g. logistic regression, decision trees)  
- Performance metrics — accuracy, precision, recall, ROC curves  
- Predictions for new input data (age, gender, spending)
